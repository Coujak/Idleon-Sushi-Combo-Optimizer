# Idleon Sushi Combo Optimizer

A browser-based Sushi Station board viewer and future combo optimizer for Legends of Idleon.

## Version 0.1
- Import Idleon Toolbox JSON with `data.Sushi` or raw game JSON with `Sushi`.
- Choose a JSON file or paste JSON into a collapsible textbox.
- Reconstruct sushi tile IDs in a 15-column board, showing displayed tier as ID + 1.
- Show parser diagnostics and empty slots.
- All import processing runs locally in the browser.

**Note:** Board reconstruction is preliminary and must be compared with an in-game screenshot. Sushi artwork and combo mechanics are not implemented yet.

To host, enable GitHub Pages for the main branch and root directory.
