CHANGELOG

Patch notes

v1.1.1

Version 1.1.1 — Fixed the first Heat upgrade: the immediate right sushi is upgraded even if it matches the merged tier; further Heat upgrades require descending original tiers.

Version 1.1.0 — Added descending domino Heat cascades, 25-upgrade limit per merge, Tier 58 trigger cutoff, row wrapping, and selectable base tiers for in-game score comparison. Scoring remains experimental.

Version 1.0.1 — Removed the incorrect recursive Heat model: one merge upgrades its destination and at most one immediately adjacent eastern sushi, without propagation or row wrapping.

Version 1.0.0 — Added base-tier sweep, three preparation patterns per base, four merge policies, selectable observed/experimental Heat behavior, and replay of the highest-scoring candidate. Predictions are not validated against in-game scores.

Version 0.9.9 — Removed the 12-step ceiling, added long adjacent-Heat cascade planning, and displayed remaining occupied slots. The planner is heuristic and may leave sushi.

Version 0.9.8 — Corrected Heat to upgrade only the immediate eastern sushi after a merge, capped consecutive Heat activations at 25, and added the tested Tier 58→42 staircase with Tier 41 supply and a fixed Tier 64 as a preparation candidate.

Version 0.9.7 — Fixed a JavaScript syntax error in the replay score display that prevented all buttons, including Paste JSON, from working. Validated JavaScript parsing.

Version 0.9.6 — Added staircase preparations based on the recording, corrected their alignment to actual board columns, and added observed-versus-simulated combo score comparison for replay steps.

Version 0.9.5 — Fixed the merge replay board scaling so all 15 columns and their tier numbers fit the smaller side-by-side layout.

Version 0.9.4 — Added interactive merge replay: board on the left, clickable steps on the right, and highlighted source, destination, and Heat of the East Wind changes.

Version 0.9.3 — Optimizer slot and recommended sushi layouts now use the same 15-column colored tile board as the imported game board.

Version 0.9.2 — Restored the missing optimizer panel and its controls, fixing null element errors during JSON import.

Version 0.9.1 — Optimizer always visible; imports no longer trigger heavy search, errors appear inline, and search is bounded for responsiveness.

Version 0.9 — Added a heuristic optimizer comparing ten prepared sushi layouts and generating step-by-step merge instructions while respecting unlocked slot positions.

Version 0.8.1 — Fixed a JavaScript syntax error that disabled the Paste JSON and import controls.

Version 0.8 — Added adjustable combo inactivity timeout and estimated merge duration, with per-move feasibility checks and execution-time estimates.

Version 0.7 — Clarified required JSON import, unlocked-slot constraints, and the combo reset rule. Salt Shaker scoring is excluded.

Version 0.6 — Added experimental Heat of the East Wind chain simulator and bounded merge search; scores are provisional, not verified maxima.

Version 0.5 — Added JSON-derived Regular, Hot, Cold and Milktoast slot colors and fireplaces by column. Hover for details.

Version 0.4 — Fixed board rendering: only occupied board slots are shown, excluding unused storage and six trailing metadata values.

Version 0.3 — Corrected Perfecto detection to treat any positive Sushi[5] value as Perfecto, consistent with Corgan’s Sushi Station tier map.

Version 0.2 — Removed sushi icons and added gold Perfecto indicators using Sushi[5]. Perfecto flag mapping awaits in-game validation.

Version 0.1 — Added Divinity-style JSON file and paste import, local parsing, diagnostics, and initial sushi board reconstruction.
