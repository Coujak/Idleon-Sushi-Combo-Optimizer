# Sushi Station Lab artwork library

All art is filed by the part of the site using it. Each icon folder includes a detailed mapping/description.

| Asset | Contents | Website usage |
| --- | --- | --- |
| [`sushi/`](sushi/) | **64/64** named tier icons, `Sushi Name (Tier X).png` | Board, Combo Meter replay, missing tiers and Perfectos |
| [`upgrades/`](upgrades/) | **46/46** named icons, `Upgrade Name (Upgrade X).png` | Upgrade Catalog, progression and Doubler advisors |
| [`shakers/`](shakers/) | Three copied Shaker images with readable names | Salt, Pepper and Saffron use counters on Overview |
| [`campfires/`](campfires/) | Five named fireplace icons matching upgrade shop numbering | Board fireplaces |
| `Perfecto_Symbol.png` | Perfecto star artwork | Perfecto markers on the board |

**Naming:** Upgrade numbers are shop list positions, distinct from their internal IDs. Sushi tier numbers are displayed tiers, distinct from zero-based sushi IDs. The site uses mapping helpers to avoid filename mistakes.

Artwork originates from *Legends of Idleon*. Game metadata is cross-checked against public community references.

## Doubler UI artwork

- `upgrade_doubler.png` — original transparent 64 × 44 Sushi Doubler icon supplied by the user, used for available/assigned Doubler counts and doubled upgrade badges in the Upgrades tab.
