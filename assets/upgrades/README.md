# Sushi Station upgrade artwork

This folder contains all **46 upgrade icons**, renamed to the form `Upgrade Name (Upgrade X).png`. **X is the upgrade's position in the Sushi Station shop list**, from 1–46; it is *not* its internal save-data ID (which runs 0–45).

Reference names and order were cross-checked against the published Sushi Station upgrade listing (Idleon Toolbox / Idleon community wiki).

Artwork is from *Legends of Idleon* and is used for identification and informational reference.
