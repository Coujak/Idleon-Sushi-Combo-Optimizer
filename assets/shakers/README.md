# Sushi Station shaker icons

Dedicated PNG **copies**, not links, of the game's three Shaker icons. The originals are also present in `assets/upgrades/` under their shop-numbered filenames.

| File | Shop upgrade | Internal ID | What it does |
| --- | --- | ---: | --- |
| `Salt Shaker.png` | Salt Shaker (Upgrade 11) | 17 | Chance to upgrade sushi tiers |
| `Pepper Shaker.png` | Pepper Shaker (Upgrade 24) | 18 | Chance to grant Perfecto status |
| `Saffron Shaker.png` | Saffron Shaker (Upgrade 34) | 19 | Grants instant Bucks based on passive earnings |

The Overview dashboard uses these icons with the imported save's `Sushi[4]` Shaker-use counts at indexes 5 (Salt), 6 (Pepper) and 7 (Saffron).
